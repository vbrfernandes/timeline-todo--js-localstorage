# Planner Carrossel Infinity

Um gerenciador de tarefas web inovador com interface baseada em linha do tempo horizontal (carrossel), suporte a tarefas recorrentes, subtarefas e múltiplos temas visuais. Desenvolvido com foco em UX moderno utilizando Glassmorphism.

## 🚀 Funcionalidades Principais

* **Timeline Infinita:** Visualização horizontal de tarefas agrupadas por dia.
* **Tarefas Recorrentes:** Criação automática de tarefas diárias, semanais ou mensais com limite de repetição.
* **Subtarefas:** Possibilidade de adicionar checklist dentro de cada tarefa principal com barra de progresso.
* **Temas Visuais:** 5 temas inclusos (Purple, Terracota, Industrial, Forest, Solar) com persistência de escolha.
* **Auto-Scroll Inteligente:** Rolagem automática do conteúdo das colunas ao passar o mouse nas extremidades.
* **Persistência de Dados:** Salvamento automático no LocalStorage do navegador.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica.
* **CSS3:** Variáveis (Custom Properties), Flexbox, Grid, Animações e Glassmorphism.
* **JavaScript (ES6+):** Manipulação de DOM, Lógica de datas, LocalStorage e Eventos.

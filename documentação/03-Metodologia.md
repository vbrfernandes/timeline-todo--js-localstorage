# Metodologia

## 1. Processo de Desenvolvimento
O projeto foi desenvolvido individualmente por **Vitor de Barros**, adotando uma abordagem ágil simplificada focada em entregas incrementais:
1.  Estruturação do Layout (HTML).
2.  Estilização e Temas (CSS).
3.  Lógica de Negócios e Persistência (JavaScript).

## 2. Tecnologias Utilizadas
* **HTML5:** Estrutura semântica da aplicação.
* **CSS3:** Estilização avançada com *Flexbox*, *Grid*, Variáveis CSS e animações.
* **JavaScript (ES6+):** Lógica de manipulação do DOM e *LocalStorage*.
* **Font Awesome:** Biblioteca de ícones.
* **Google Fonts:** Tipografia (Fonte Inter).

## 3. Ferramentas
* **Editor de Código:** Visual Studio Code.
* **Versionamento:** Git (Controle local).
* **Navegador:** Google Chrome (Ferramentas de desenvolvedor para testes).

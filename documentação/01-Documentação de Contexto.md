# Documentação de Contexto

**Projeto:** Planner Carrossel Infinity
**Desenvolvedor:** Vitor de Barros
**Data:** Janeiro/2026

## 1. Introdução
O projeto consiste em uma aplicação web de gerenciamento de tarefas denominada **"Planner Carrossel Infinity"**. Trata-se de um sistema *Front-End* que utiliza o conceito de linha do tempo horizontal (carrossel) para organizar atividades diárias. A aplicação destaca-se pelo design moderno baseado em *Glassmorphism*, suporte a múltiplos temas visuais e persistência de dados local (*LocalStorage*).

## 2. Problema
No cotidiano acelerado, muitas pessoas têm dificuldade em visualizar suas tarefas de médio prazo de forma contínua. As listas de tarefas tradicionais (verticais) muitas vezes não oferecem uma perspectiva temporal clara. Além disso, a gestão de tarefas recorrentes costuma ser manual e trabalhosa, levando à desorganização.

## 3. Objetivos
O objetivo geral é desenvolver uma aplicação de produtividade intuitiva e visualmente engajadora.
**Objetivos específicos:**
* Implementar uma interface de linha do tempo horizontal navegável.
* Automatizar a criação de tarefas recorrentes (diárias, semanais, mensais).
* Oferecer personalização visual (Temas).
* Garantir o funcionamento *offline* (armazenamento local).

## 4. Justificativa
A organização visual é fundamental para a produtividade. A escolha por uma aplicação *client-side* (sem banco de dados externo) justifica-se pela privacidade total dos dados do usuário e pela rapidez de resposta da interface.

## 5. Público-alvo
* **Perfil:** Estudantes, freelancers e profissionais que lidam com múltiplos prazos.
* **Faixa etária:** Jovens e adultos (16 a 45 anos).
* **Interesses:** Tecnologia, métodos de organização visual e personalização de interface.

# Especificação do Projeto

## 1. Perfis de Usuários

| Perfil | Descrição | Necessidades |
| :--- | :--- | :--- |
| **Estudante** | Precisa gerenciar prazos de estudos e entregas. | Visualizar a semana inteira; Repetir tarefas de aulas semanais. |
| **Profissional** | Gerencia tarefas diárias de trabalho. | Subdividir tarefas complexas (checklists); Ver gráfico de progresso diário. |

## 2. Histórias de Usuários

| Eu como... | ... quero/desejo ... | ... para ... |
| :--- | :--- | :--- |
| Usuário | Visualizar tarefas horizontalmente | Entender melhor minha linha do tempo. |
| Usuário | Trocar o tema da aplicação | Personalizar o visual conforme meu gosto. |
| Usuário | Criar tarefas que se repetem | Não ter que digitar a mesma tarefa todo dia. |
| Usuário | Salvar meus dados automaticamente | Não perder informações ao fechar o navegador. |

## 3. Requisitos do Projeto

### Requisitos Funcionais (RF)
| ID | Descrição | Prioridade |
| :--- | :--- | :--- |
| **RF-01** | Criar, editar e excluir tarefas. | Alta |
| **RF-02** | Criar tarefas com repetição (diária, semanal, mensal). | Alta |
| **RF-03** | Visualizar tarefas em carrossel horizontal. | Alta |
| **RF-04** | Adicionar subtarefas (checklist). | Média |
| **RF-05** | Visualizar progresso (gráfico e contagem). | Média |
| **RF-06** | Trocar temas visuais. | Baixa |

### Requisitos Não Funcionais (RNF)
| ID | Descrição | Prioridade |
| :--- | :--- | :--- |
| **RNF-01** | Responsividade (Desktop e Mobile). | Alta |
| **RNF-02** | Estilo visual Glassmorphism. | Média |
| **RNF-03** | Persistência via LocalStorage. | Alta |
